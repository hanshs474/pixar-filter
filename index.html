Getting a usable result

The likeness comes from the shapes, so a photo with clear features beats a moody one with half the face in shadow.

Busy backgrounds get simplified along with everything else. That is usually an improvement.

A prompt that works

Restyle the person in the photo as a stylized 3D animated feature-film character: a rounded head with big expressive eyes, smooth soft-shaded skin with a warm subsurface glow, sculpted hair, clean cinematic key light with a soft rim, glossy render finish. Keep the same identity readable — same hair colour, same facial hair, same glasses, same clothing colour, same expression and pose. 3D animation render, not a flat cartoon drawing.

That is the same prompt the Pixar Filter for Photos on Kavel starts you with, so you can run it here first and take it over there when you want the higher-resolution model.
